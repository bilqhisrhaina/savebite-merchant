# Merchant Flow
# SaveBite Merchant Dashboard


# 1. Login Merchant Flow


Merchant membuka website

        ↓

Halaman Login Merchant

        ↓

Input:
- Email
- Password

        ↓

Klik Login

        ↓

Masuk ke Dashboard Merchant



--------------------------------------------------


# 2. Dashboard Merchant Flow


Merchant masuk dashboard

        ↓

Melihat informasi:

- Produk aktif
- Pesanan hari ini
- Jumlah makanan yang diselamatkan

        ↓

Merchant dapat memilih menu:


1. Kelola Produk

2. Pesanan Masuk

3. Profil Restoran

4. Bantuan



--------------------------------------------------


# 3. Tambah Produk Flow


Dashboard

        ↓

Klik tombol:
"+ Tambah Produk"

        ↓

Halaman Tambah Produk


Merchant mengisi:

- Foto makanan
- Nama produk
- Deskripsi
- Harga normal
- Harga surplus
- Jumlah stok
- Waktu pengambilan


        ↓

Klik:
"Publikasikan Produk"


        ↓

Validasi data produk


        ↓


Produk berhasil ditambahkan


        ↓


Produk muncul pada halaman:
"Produk Aktif"



--------------------------------------------------


# 4. Kelola Produk Flow


Merchant membuka:

Kelola Produk


        ↓


Melihat daftar makanan surplus


        ↓


Pilihan aksi:


## Edit Produk

Klik Edit

        ↓

Mengubah informasi produk

        ↓

Simpan perubahan



## Nonaktifkan Produk

Klik Status Aktif

        ↓

Produk menjadi tidak tersedia



## Hapus Produk

Klik Hapus

        ↓

Konfirmasi penghapusan

        ↓

Produk dihapus



--------------------------------------------------


# 5. Pesanan Masuk Flow


Customer melakukan reservasi makanan


        ↓


Pesanan masuk ke dashboard merchant


        ↓


Merchant melihat detail:

- Kode pesanan
- Nama makanan
- Jumlah
- Waktu pengambilan


        ↓


Merchant memproses pesanan


        ↓


Status berubah:


Belum Diambil

        ↓

Selesai



--------------------------------------------------


# 6. Profil Restoran Flow


Merchant membuka Profil


        ↓


Melihat informasi:

- Nama restoran
- Foto restoran
- Lokasi
- Kontak


        ↓


Klik Edit Profil


        ↓


Update informasi


        ↓


Simpan perubahan



--------------------------------------------------

        ↓
